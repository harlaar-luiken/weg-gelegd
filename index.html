Database Connectie (Supabase)

Voor synchronisatie tussen je computer en telefoon gebruiken we een gratis Supabase project. Vul hieronder je project URL en API Key (anon-key) in. Deze gegevens worden veilig lokaal in je browser bewaard.

Geen verbinding met Supabase (Demo-modus actief)

Hoe stel ik Supabase in?

  1. Ga naar supabase.com en maak een gratis account aan.
  2. Maak een nieuw project genaamd weg-gelegd.
  3. Ga in je Supabase dashboard naar de SQL Editor en voer de SQL scripts uit (zie de documentatie).
  4. Maak een openbare Storage bucket genaamd photos voor afbeeldingen.
  5. Kopieer de Project URL en API Key van de Settings > API pagina en plak ze hierboven.
